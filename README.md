# Jivantag Business Website

Static HTML/CSS/JavaScript website prepared for GitHub Pages.

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — mobile menu and current year
- `images/` — supplied Jivantag logo and website artwork

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the complete `images` folder.
3. Keep `index.html` in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will provide the public Pages URL.

The site uses no frameworks or build tools, so it can be hosted directly from GitHub Pages.
